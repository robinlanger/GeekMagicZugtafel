# Glance Box add-on

Server for the [Glance Box](https://github.com/robinlanger/glancebox) display: open firmware for
the GeekMagic SmallTV Ultra (ESP8266, 240x240) that shows any HTML page. This add-on renders the
pages and the display fetches them over your LAN.

After installing: click **Open web UI** and enter the server address shown there in
the display. See the Documentation tab for details.
